# ROBOFEST 2027 Simulator

ROBOFEST 2027 Game 경기장을 기준으로 로봇의 주행 경로와 미션 수행을 연습하는 **브라우저 기반 2D 시뮬레이터**입니다.

> 이 프로젝트는 주행 전략 연구용 모델입니다. 실제 경기장의 물리적 특성, 로봇의 구동 성능, 센서 감지 및 심판 판정을 정확히 재현하지 않습니다.

## 실행

`index.html`을 Chrome 등 최신 브라우저에서 열면 됩니다. 별도 서버나 빌드 과정은 필요하지 않습니다.

## 기본 사양

| 항목 | 설정 |
| --- | --- |
| 경기장 | 182 × 75 cm |
| 로봇 | 가로 20 × 세로 30 cm 직사각형 |
| 로봇 질량 | 7 kg (모델상 가정) |
| 주행 | 좌우 엔코더 모터 기반 주행 모델 |
| 센서 | 전면 및 후면 라인 센서 |
| 위치 보정 | 검은선·경기장 경계를 이용한 보정 |
| 경기 제한시간 | 120초 (시간 초과 후에도 연습 가능) |

## 조작

| 키 | 기능 |
| --- | --- |
| ↑ / ↓ | 전진 / 후진 (키를 누르는 동안) |
| ← / → | 입력 1회당 15° 부드러운 좌/우회전 |
| Q / E | 90° 좌/우회전 |
| G | 전면 팔·집게로 여러 물체 잡기 / 놓기 |
| M | 인접한 설비의 미션 시작 |
| C | 센서 기준 위치·방향 보정 |
| Space | 정지 |
| P | 일시정지 |
| Shift | 고속 주행 |

화면의 터치 버튼으로도 조작할 수 있습니다.

## 구현 기능

- 기본 경기장 및 강아지, 고양이, 우편함, 사료 디스펜서, 펫호텔, 펫토이 등을 표현
- 전면 집게에 들어온 **여러 물체 동시 포획**과 밀기
- 차체 폭 20cm의 초록색 주행 흔적, 최근 경로를 진하게 표시
- 주행·회전에 따른 **위치/방향 오차 누적 추정** 및 보정 부족 경고
- 물체별 기본 배치에서 X·Y 각각 ±2cm 위치 변경 및 랜덤 편차
- Food Dispenser, Pet Hotel, Pet Toy의 작업 시간 조절
- 종료 시 연습 점수와 세부 점수 출력
- 120초를 초과하더라도 운전 가능하며 종료 시 **시간 초과 표시**
- 주행 기록 재생과 JSON 내보내기
- **추천 경로 시험**: 시작 → Food Dispenser → Pet Hotel → Pet Toy → 종료 위치
  - 현재 추천 경로는 기본 배치에서만 검증한 예시이며 나머지 과제는 포함하지 않음

## 검증

`tests/regression.py`는 Playwright와 Chromium이 설치된 환경에서 실행합니다.

```bash
python -m pip install playwright
python -m playwright install chromium
python tests/regression.py
```

기본 배치에서 추천 경로의 연습 점수는 **61/100점**, 시뮬레이션 시간은 **약 67초**입니다. 공식 경기에서 동일한 점수를 보장하지 않습니다.

## 소스코드

- `index.html` — 전체 애플리케이션 (HTML/CSS/JavaScript)
- `tests/regression.py` — 주요 조작 및 자동 경로 회귀 테스트

## 주의

- 경기 종료 과제 및 점수 계산은 단순화된 모델입니다.
- 실제 물체 무게, 집게 형상, 바퀴 마찰, 관성, 센서 오차는 별도 실험으로 검증해야 합니다.
- 화면상 연습은 수동 조종이며, 실제 대회에서 요구하는 자율주행 코드는 포함하지 않습니다.
